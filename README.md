# Nike-inspired storefront (React.js)

A premium Nike-inspired footwear and sportswear shopping experience built with React, React Router, and responsive CSS. The visual direction is original and uses the existing product imagery and catalog data.

## Features

- Editorial single-page home experience with scroll reveals and responsive navigation
- Product catalog, category pages, product details, and featured slider
- Transparent sneaker cutouts and a dark showroom-inspired visual system
- Guest-accessible cart with quantity controls, local persistence, and cart feedback
- Validated Cash on Delivery demo checkout and order confirmation

## Run locally

```bash
npm install
npm start
```

The demo stores carts and orders in the visitor's browser. It has no server, database, real payment processing, inventory service, or production authentication. Do not use it for real customer data.

## How to run
1. Clone the repo
2. Run `npm install`
3. Run `npm start`
